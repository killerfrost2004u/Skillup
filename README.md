## About

**Skillup** is a repository created to help people study programming from their homes. Whether you're trying to learn new skills, contribute to open-source projects, or showcase your work, Skillup serves as the perfect place to get started.

### Why this project?

- It helps EVERYONE to learn Programming and achieve their passion easily 
- Anyone older than 7 years old will benefit from our WebSite
- Our WebSite stands out by it's simple yet efficient UI/UX

### Prerequisites

Ensure you have the following software installed:

- [VsCode ]
- [python 3.18+]
- [SQL Server Management Studio 21 or more]

### Installation

Clone the repository:

```bash
git clone https://github.com/killerfrost2004u/Skillup.git
cd Skillup
```
